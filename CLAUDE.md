# CLAUDE.md — инструкции для AI-агента

Этот файл Claude Code читает в начале каждой сессии. Здесь собраны
постоянный контекст проекта и договорённости по работе с кодом.

## Проект

«Семейный бюджет» — веб-приложение для совместного учёта доходов и расходов
семьи (аналог мобильных приложений учёта финансов). Учебный проект курса
по разработке с AI-агентами: каждое ДЗ — следующий этап одного продукта.

## Стек (целевой)

- Frontend: React 19 + TypeScript + Vite, Tailwind CSS, Recharts
- Тесты: Vitest + Testing Library (в sandbox/hw1-test — встроенный `node:test`)
- Backend: Supabase (PostgreSQL, Auth, RLS, REST API)
- Деплой: Vercel, CI/CD — GitHub Actions

## Структура репозитория

- `docs/hwN/` — отчёты и артефакты по домашним заданиям
- `sandbox/` — тестовые и экспериментальные проекты
- `src/` — код приложения (появится в ДЗ4)

## Правила работы

- Язык интерфейса, комментариев и документации — русский; имена в коде — английские.
- TypeScript в строгом режиме, `any` запрещён.
- Деньги храним в числах с двумя знаками после запятой (в БД — `numeric(12,2)`),
  форматируем только через `formatMoney`.
- Каждая новая функция или компонент сопровождается тестами; тесты должны проходить.
- Секреты (ключи Supabase, OAuth) — только в `.env`, никогда в коде и в git.
- Перед изменением чужого кода — прочитать файл целиком; после изменения — запустить тесты.
- Вёрстка mobile-first: проверять ширину 360px, без горизонтального скролла.
