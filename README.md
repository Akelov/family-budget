# Семейный бюджет

Веб-приложение для совместного учёта доходов и расходов семьи — аналог мобильных
приложений учёта бюджета. Члены семьи записывают операции с категорией и подкатегорией,
тегами и комментарием, смотрят отчёты и следят за бюджетами.

Учебный проект: разработка с помощью AI-агента (Claude). Правила агента — [CLAUDE.md](CLAUDE.md).

**Онлайн-версия:** https://akelov.github.io/family-budget/ (публикуется автоматически из ветки `main`).

## Что умеет (версия ДЗ4)

| Раздел | Возможности |
|---|---|
| **Операции** | Период (месяц, свой цикл с дня N, произвольный диапазон), сводка «Доход / Расход / Остаток», история по дням с итогом дня, поиск, фильтры по типу, категориям, тегам и авторам, добавление, изменение и удаление с отменой |
| **Отчёты** | Кольцевая диаграмма и список с долями (в сумме ровно 100 %), раскрытие категории до подкатегорий, переход к операциям, вкладка «Теги» |
| **План** | Бюджеты по периоду семьи: потрачено, осталось, процент, статусы «В норме» / «Почти у лимита» / «Превышен на N ₽», создание и изменение |
| **Настройки** | Профиль и личный вид периода, период семьи, категории и подкатегории (архив, удаление), теги (переименование, объединение), участники и роли |

Права ролей «Владелец», «Администратор», «Участник» соблюдаются по матрице из ТЗ.
Телефон — нижняя панель с кнопкой «+», десктоп (от 1024 px) — верхняя панель и таблица операций.

> **Данные пока мок-данные.** Сервер (Supabase) подключается в ДЗ5. Сейчас данные выдуманной
> семьи хранятся в браузере (localStorage), запросы имитируют задержку сети.
> В «Настройки › Для разработчика» можно войти от имени другого участника, включить имитацию
> ошибки сети или сервера и сбросить демо-данные. Две вкладки браузера синхронизируются,
> как будто изменения приходят от другого участника.

## Стек

React 19 · TypeScript (strict) · Vite 7 · Tailwind CSS 4 · React Router 7 · Recharts 3 ·
lucide-react · Vitest 3 + Testing Library · ESLint 9 + Prettier · GitHub Actions + GitHub Pages.

## Запуск

Нужен [Node.js](https://nodejs.org) 20.19 или новее (рекомендуется 22 LTS, см. `.nvmrc`).

```bash
git clone https://github.com/Akelov/family-budget.git
cd family-budget
npm install
npm run dev          # http://localhost:5173 — с горячей перезагрузкой
```

| Команда | Что делает |
|---|---|
| `npm run dev` | локальный сервер разработки с hot reload |
| `npm test` | все автотесты (Vitest) |
| `npm run test:watch` | тесты в режиме наблюдения |
| `npm run lint` | ESLint |
| `npm run typecheck` | проверка типов TypeScript |
| `npm run build` | сборка в папку `dist` |
| `npm run preview` | просмотр собранной версии на http://localhost:4173 |

## Структура

```text
src/
  app/          точка входа, роутер, каркас (верхняя и нижняя панели)
  pages/        страницы-маршруты: Операции, Отчёты, План, Настройки
  features/     фичи: transactions, reports, budgets, period, categories, tags, household, settings
    <фича>/api         запросы к «серверу» (в ДЗ5 — Supabase)
    <фича>/model       чистая бизнес-логика и её unit-тесты
    <фича>/hooks       хуки фичи
    <фича>/components  компоненты фичи
  shared/       общие UI-компоненты, утилиты (деньги, даты), мок-сервер, типы
  test/         настройка тестов, фикстуры, рендер приложения
```

Деньги считаются в копейках (целые числа), даты — строками `YYYY-MM-DD` без часовых поясов.

## Деплой

Каждый push в `main` запускает [GitHub Actions](.github/workflows/ci.yml): линтер, типы,
тесты, сборка и публикация на GitHub Pages. Для Vercel готов `vercel.json` (сборка с `VITE_BASE=/`).
