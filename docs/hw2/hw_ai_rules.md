## 1. Описание проекта

«Семейный бюджет» — веб-приложение для совместного учёта доходов и расходов
семьи. Аналог мобильных приложений учёта финансов, но рассчитанный на несколько
человек: члены семьи ведут общий бюджет, видят операции друг друга, задают
месячные лимиты по категориям и следят за их соблюдением.

**Функции MVP:**

1. Регистрация и вход, создание семьи, приглашение участников.
2. Учёт операций: доходы и расходы, добавление, редактирование, удаление, фильтры.
3. Категории и месячные лимиты по категориям с предупреждением о превышении.
4. Дашборд: баланс месяца, структура расходов, динамика по месяцам.

**Особенность предметной области:** приложение работает с деньгами и данными семьи.
Отсюда повышенные требования к точности расчётов (никаких ошибок округления),
к разграничению доступа (одна семья не видит данные другой) и к защите секретов.

## 3. Ключевые требования к коду

**Архитектура:**
- Структура по фичам (`features/transactions`, `features/budgets`, …) плюс общий слой `shared/`.
- Бизнес-логика (суммы, остатки, лимиты) — только в чистых функциях без React и сети. Её легко тестировать, и агент не смешивает расчёты с отображением.
- Страницы тонкие: только собирают компоненты фич.

**Стиль кода:**
- Именование: `PascalCase` для компонентов и типов, `camelCase` для функций и хуков, `UPPER_SNAKE_CASE` для констант.
- Код на английском, интерфейс и комментарии на русском.
- Короткие функции с одной ответственностью, JSDoc для бизнес-логики.
- Prettier: 2 пробела, одинарные кавычки, ширина 100.

**Стандарты разработки:**
- Тесты к каждой функции бизнес-логики и к компонентам: позитивный сценарий, краевой случай, ошибка.
- Каждый компонент с загрузкой данных обрабатывает состояния loading / error / success / empty.
- Mobile-first: интерфейс проверяется на ширине 360px.
- Деньги считаются в копейках (целых числах), форматируются одной функцией `formatMoney`.
- Секреты только в переменных окружения, доступ к данным ограничен RLS.

Все эти требования формализованы в файле правил агента: [rules.md](rules.md).
