# Шаг 5. Платёжный сервис — не требуется

Шаг необязательный («если требуется»). Владелец продукта решил его пропустить:

- «Семейный бюджет» — бесплатное приложение для семьи, в ТЗ (ДЗ3) нет платных функций,
  подписок и покупок;
- подключение ЮKassa или Stripe ради демонстрации добавило бы в продукт функцию, которой
  нет в требованиях, и обработку платёжных данных — лишний риск без пользы.

Если понадобится (например, платная подписка «Премиум»), архитектура готова: платёж
создаётся серверной функцией Vercel в `api/` (секретный ключ ЮKassa — только в переменных
окружения Vercel), уведомления принимает webhook `api/payments/webhook` с проверкой подписи,
статус подписки хранится в Supabase и защищается RLS.
