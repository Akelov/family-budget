# Дизайн-токены (итоговая концепция 4)

Значения сняты из `globals.css` проекта концепции 4 в v0.dev и используются в макетах
всех экранов (`sandbox/hw3-mockups/src/styles.css`). В ДЗ4 переносятся в тему Tailwind.

| Токен | Значение | Где используется |
|---|---|---|
| `--background` | `#f4f6f5` | фон страницы |
| `--foreground` | `#141a17` | основной текст |
| `--card` | `#ffffff` | карточки, панели |
| `--muted` | `#eef1ef` | фон переключателей, иконок категорий |
| `--muted-foreground` | `#6a716d` | второстепенный текст |
| `--border` | `#e4e7e5` | разделители |
| `--primary` | `#33875c` | акцент, кнопки, доходы |
| `--accent` / `--accent-foreground` | `#e1f4e8` / `#104f32` | чипы тегов, статус «В норме» |
| `--destructive` | `#d33a3c` | расходы, «Превышен» |
| `--warning` | `#d9971f` | «Почти у лимита» (добавлен для бюджетов) |
| `--radius` | `14px` (карточки — `20px`) | скругления |
| Шрифт | Inter | весь интерфейс; цифры — `tabular-nums` |

Цвета категорий в отчётах: Дом `#33875c`, Продукты `#e0a43a`, Автомобиль `#4c7fd1`,
Дети `#c2618b`, Кафе `#8a6fd1`, Прочее `#9aa59f`.
